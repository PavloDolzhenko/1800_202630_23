# Spot the Bot


## Overview
Spot the Bot is a client-side web game that challenges users to tell AI-generated content apart from the real thing. Players are shown a series of images, text snippets, or other media and must guess whether each one was created by a human or generated by AI, scoring points for correct guesses and building an intuition for the tells that give synthetic content away.

The app is designed to sharpen media literacy in an age of increasingly convincing AI-generated content, turning a serious skill spotting deepfakes, synthetic text, and AI imagery into a quick, replayable game rather than a lecture.

Developed for the COMP 1800 course, this project applies User-Centred Design practices and agile project management, and demonstrates integration with Firebase backend services for storing game data such as scores and progress.

---


## Features

- Play through a series of rounds guessing whether each image, text snippet, or clip is AI-generated or real
- Instant feedback after each guess, showing the correct answer and a running score
- Score tracking to see how your "AI-detection" accuracy improves over time
- Responsive design for desktop and mobile

## Usage

To run the application locally:

1.  **Clone** the repository.
2.  **Install dependencies** by running `npm install` in the project root directory.
3.  **Start the development server** by running the command: `npm run dev`.
4.  Open your browser and visit the local address shown in your terminal (usually `http://localhost:5173` or similar).

Once the application is running:

1.  Look at each image, text snippet, or clip presented on the main page.
2.  Guess whether it's **AI-generated** or **real** by clicking the corresponding button.
3.  See instant feedback on whether your guess was correct, and watch your score update.
4.  Keep playing to improve your accuracy and see your final results at the end of the round.
